# Professional Personal Portfolio

A static, responsive personal portfolio website built with pure HTML5 and CSS3. 

## Features

- **Responsive Design**: Mobile-first approach using Flexbox and Grid.
- **Theme**: Dark mode aesthetic (Blue + Black).
- **No JavaScript**: Pure CSS implementation for all interactive elements (mobile menu, hover effects).
- **PWA Ready**: Includes specific manifest and structure for progressive web app standard.
- **Pages**: Home, About, Skills, Projects, Contact.

## Project Structure

```
portfolio-website/
├── index.html          # Home
├── about.html          # About Me
├── skills.html         # Skills
├── projects.html       # Projects 
├── contact.html        # Contact
├── css/
│   └── style.css       # Main styles
├── assets/             # Assets directory
└── manifest.json       # PWA Manifest
```

## How to Run

1. Unzip the folder.
2. Open `index.html` in any modern web browser.

## Customization

- **Colors**: Edit the CSS variables in `:root` inside `css/style.css`.
- **Content**: Update the HTML files with your own information.
